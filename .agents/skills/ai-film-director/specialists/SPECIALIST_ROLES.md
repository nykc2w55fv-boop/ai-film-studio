# 专业岗位目录

下列 `ROLE.md` 是总导演按需读取的专业模块，不是已注册的独立 Skill。路由先选择任务，再选择岗位；阶段输出必须写入项目模板并通过相应质量门槛。

| 岗位 | 主要触发 | 主要交付 |
| --- | --- | --- |
| research | 事实、原典、来源不明 | 研究日志与事实边界 |
| screenwriting | 故事、人物、对白 | 故事圣经与剧本 |
| directing | 情绪、表演、场面意图 | 场面调度与分镜意图 |
| cinematography | 画面语言与镜头方案 | 视觉圣经与镜头参数 |
| storyboard | 镜头拆解与空间关系 | 分镜计划 |
| art-direction | 角色、场景、道具风格 | 视觉设定与资产约束 |
| sound-design | 台词、音效、音乐与声场 | 音频提示表 |
| editing | 节奏、转场与组接 | 剪辑方案 |
| visual-effects | 视效选型、合成与虚实衔接 | 视效镜头方案、素材采集要求与合成检查 |
| continuity | 跨场景/镜头一致性 | 连续性记录 |
| production | 资源、批次、状态和交付 | 项目状态与交付清单 |

同一产物可由多个岗位协作，但必须有一个主责岗位；不足以证明真实媒体完成时只标 `planned`。

八个大师方法领域与岗位、阶段的对应关系见 `DOMAIN_STAGE_MAP.md`。research、continuity、production 为跨阶段职责；加入 visual-effects 后共有 11 个岗位，不为统一数字删减既有模块。
