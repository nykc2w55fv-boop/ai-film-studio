# MASTER_METHOD_PACKAGE.md 结构与验收

本文件是旧式单文件 Markdown 导入器的兼容格式说明。现行 14 位 Markdown／ZIP 构建流程使用方法级证据状态与调用权限，不要求逐位 `verified` 才能作受限创作参考。

## 文件与元数据

ChatGPT 交付物类型叫 `MASTER_METHOD_PACKAGE.md`；为使多人研究包能并存，放入接收目录时命名为 `03_KNOWLEDGE/master-research/ready-for-skill/<slug>.md`。文件为 UTF-8 Markdown，首行为 `# MASTER_METHOD_PACKAGE`，其后连续七个 `- key: value` 字段：`slug`、`name_zh`、`name_en`、`field`、`status`、`representative_works`、`summary`。`slug` 为小写字母、数字和连字符，必须与候选索引一致；`field` 必须匹配索引；正式导入要求 `status: verified`。测试资料可用 `status: simulation`，只允许检查和预览。

必须按模板提供以下二级标题：`核心方法`、`本人明确表达`、`研究者归纳`、`证据台账`、`作品案例`、`适用与局限`、`可执行步骤`、`AI 短片迁移规则`、`测试案例`、`来源列表`。每节须有实质文字；`核心方法`、`研究者归纳`、`证据台账` 和 `作品案例` 至少含一个来源编号 `[S1]`；来源列表提供对应编号与可定位信息。测试案例包含输入、期望输出和失败判据。脚本能检查结构与引用编号，不能证明来源真实或技法正确。

## 人工验收门槛

- 研究对象和专业领域明确；英文名和代表作品由来源核实。
- 核心方法可追溯，明确区分本人直接表达和研究者归纳；没有直接证据时必须明确写“未找到可核实的一手表述”。
- 至少一个具体作品案例、适用范围、局限、可执行步骤、AI 短片迁移规则和测试案例。
- 对在世创作者仅提炼通用专业技法，不要求直接模仿可识别个人风格。
- 证据不足时改为 `provisional`，仅保留研究包，不生成正式 Skill。批量导入只读 `ready-for-skill/` 的 Markdown 文件。

上述 `verified` 门槛仅适用于旧导入器的“正式导入”命令；它不阻断本轮受限方法路由。结构检查成功也不代表事实已获证实。
