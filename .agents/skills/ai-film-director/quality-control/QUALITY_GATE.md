# 生产质量门槛

每阶段先检查输入版本和确认状态，再检查产物。结果写入项目 `10_quality-control/QA_REPORT.md`，注明检查的是方案、真实素材还是成片。没有真实文件不能通过媒体生成或成片验收。

| 检查域 | 最低通过条件 | 主责 |
| --- | --- | --- |
| 史实与原典 | 关键主张有可定位来源，改编标记清楚 | research |
| 人物动机与剧情 | 选择、阻力、后果和转折有因果 | screenwriting |
| 场景逻辑 | 时间、地点、人物行动可衔接 | directing |
| 视觉与人物 | 风格、角色身份、光色、服装道具一致 | art-direction/continuity |
| 镜头 | 编号、轴线、视线、动作接续可追 | storyboard/cinematography |
| 声音与画面 | 台词可懂，音效与动作时序一致 | sound-design/editing |
| 节奏与字幕 | 时长符合目标，字幕准确可读 | editing |
| 版权与来源 | 素材来源、许可和使用范围有记录 | production |

等级：**致命**必须修复后再推进；**重要**修复后重新验收；**一般**记录责任人与处理时间。致命例子包括关键事实伪造、未授权素材和错误人物身份；一般问题不能掩盖更高等级问题。
