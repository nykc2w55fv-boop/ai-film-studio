# Skill 验收清单

- `SKILL.md` 有 YAML frontmatter，至少含非空 `name` 和面向任务的 `description`。
- 总导演入口只含路由、阶段、批次、质量与确认，不把全部岗位全文塞入根文件。
- 岗位 `ROLE.md` 仍是模块，不能标为独立 Skill；所有相对引用存在且大小写一致。
- 大师 Skill 一人一目录，含四个 references 文件和一个 evals 文件；来源可追，适用与局限、测试案例完整。
- `MASTER_INDEX.md`、`MASTER_ROUTING.md` 和构建包 `methods-index.json` 对应；方法逐项记录证据状态和调用权限。`provisional` 资料可在 `LIMITED` 或 `SANDBOX` 约束下辅助创作，不能作已核实事实引用。
- 原研究包保持只读；失败或重复导入不覆盖已有 Skill。
- 结构校验后还需实际 Codex 触发与 ChatGPT 各端交接验收；重要来源冲突或关键归因不明才进入人工决策。
