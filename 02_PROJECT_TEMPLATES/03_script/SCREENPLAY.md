# 剧本

封面填写项目代号、标题、版本、作者、目标时长和状态（草案/待确认/已锁定）。剧本定稿确认后锁定版本；修改需记录原因和重新确认。

## 场景格式

`SC01｜内/外｜地点｜时间`。其下依次写：场景目标、可见动作、对白/旁白、声音、事实/改编标记、预计时长和对应研究编号。示例字段只是格式说明，不能当作实际剧情。

## 压力测试与修订
